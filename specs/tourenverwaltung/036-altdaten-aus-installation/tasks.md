# Aufgaben: 036 – Installation ohne Altdatenübernahme

- [ ] 1. Lesecode zum Erkennen von Altdaten samt Tests löschen (`ErkenneAltdaten`, `Altdatenfund`, `Altdatenart`)
- [ ] 2. Aufzeichnungsübernahme des Umwandlungsprogramms samt Tests löschen (`ErstelleAufzeichnungsordner`, `Aufzeichnungsergebnis`, `ErstelleAufzeichnungsbericht`)
- [ ] 3. Aufrufarten und Rückgabecodes des Umwandlungsprogramms auf das Umwandeln beschränken (`Programmmodus` löschen; `Aufrufparameter`, `LeseAufrufparameter`, `Rueckgabecode`, `Program`, `ErstelleZwischenordner` anpassen)
- [ ] 4. `LeseAufrufparameterTests` anpassen; Bauen und Testen ohne Fehler und Warnungen
- [ ] 5. Bauskript: Umwandlungsprogramm nicht mehr veröffentlichen
- [ ] 6. Installationsprogramm: Übernahme-Seite, Werkzeug und Rückgabecodes entfernen; Zusammenfassung anpassen
- [ ] 7. Installationsprogramm: Meldungen zum vorhandenen und zum nicht leeren Datenordner anpassen
- [ ] 8. Installationsprogramm: altes Umwandlungsprogramm bei der Aktualisierung entfernen und im Protokoll vermerken
- [ ] 9. Installationsprogramm bauen
- [ ] 10. Handbuch: Übernahme-Stellen entfernen, Abschnitte in Kapitel 2 neu nummerieren, Glossar anpassen
- [ ] 11. Handbuch: Hinweis auf den FIT-Import in 3.5
- [ ] 12. Manuelle Prüfung: Neuinstallation (Seiten, Zusammenfassung, Programmordner, Protokoll, leerer Datenordner)
- [ ] 13. Manuelle Prüfung: Datenordner mit AndyTours-Daten und mit fremden Dateien
- [ ] 14. Manuelle Prüfung: Aktualisierung über Version 1.0.1
