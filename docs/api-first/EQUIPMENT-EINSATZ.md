# Equipment-Einsatz und Haltbarkeit

**Einsatzbericht angebunden; Haltbarkeitsabläufe bleiben getrennt.** `GET /api/v1/equipment-einsatz` liefert ungefiltert alle Legacy-Anzeigezeilen. `ErmittleEquipmenteinsatz` aggregiert je Equipment Anfangs-km, Gesamtkilometer und Höhenmeter; fehlende/verwaiste Zuordnungen stehen unter „ohne Equipment“, eine vorhandene Summe bleibt zuletzt. Auf 0 gerundete km-Zellen sind leer, die übrigen Werte bleiben ungerundet. Ausgemusterte Geräte tragen den Anzeigezusatz. Die API-Zeilen enthalten bewusst keine ID; Namen sind keine Identität.

Der API-Client prüft die Summenzeile und endliche km-Werte. `ApiEquipmentEinsatzViewModel` kopiert die Zeilen und nutzt `SortiereEinsatzzeilen` lokal: stabile Sortierung, leere Zahlen als 0, Summe zuletzt. Das besitzgebundene Modal liegt unter Extras und nennt den ungefilterten Umfang. Kein First-/Last-Nutzungsdatum oder Fahrzeitwert ist Teil des Berichts.
